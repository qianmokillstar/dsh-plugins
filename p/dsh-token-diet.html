dsh-token-diet · Token 账本与会话预算

已核实 人工短评 风险 低 🟢 纯本地
一句话结论：给每个会话设一条 Token 预算红线，吃到 80% 变橙、100% 在下一步请求前直接停下——治"聊到停不下来"最直接的一招。

适合谁

  • 长会话、长任务容易一晚上烧掉预算，需要硬性止损的人。
  • 同时用多个供应商/模型，想按日期×供应商×模型×工作区看用量的人。
  • 想把"本地模型按 0 计算"、避免统计虚高的人。

解决什么

  • Token 统计页：汇总本机所有会话、子智能体与自动化任务，给出总 Token、估算成本、缓存命中率、日均成本、按天趋势、按模型/工作区明细。
  • 会话预算：输入框模型名右侧填上限（含该会话派生的子智能体），80% 变橙提醒，100% 在下一步模型请求前停下，弹窗可直接"提高预算并继续"。
  • 价格与汇率：价格取自 models.dev，默认人民币、可切美元，汇率联网更新、支持手动覆盖，查不到的模型可自定义价格。
  • 模型名映射：拼写不同但实为同一模型时按标准模型计价，并明确标注"不精确的模糊匹配"。

风险点

  • 预算是估算：价格来自第三方目录 models.dev + 汇率联网，报价过期或映射不准时，红线位置会漂移。
  • 停任务是真的停——100% 时会在下一步请求前中断，长任务可能卡在半路，需要手动提高预算。
  • 会计入子智能体消耗，所以"单会话预算"实际是整棵子树的预算，容易比预期更早触顶。
  • 与 dsh-cost-meter 功能重叠，同时装会出现两套价格/两套统计，数字可能不一致。

替代品

  • dsh-cost-meter：更偏历史归因、套餐额度聚合，预算提醒没那么硬。
  • 官方用量显示：只看当轮，没有预算红线。
  • 什么都不装 + 自己看账单：最省事，但发现时已经花完了。
