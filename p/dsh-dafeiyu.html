dsh-dafeiyu · 大肥鱼桌面伴侣

已核实 人工短评 风险 中 🟢 纯本地
一句话结论：真正的原生置顶小窗（不是网页挂件），随 DSH 启动退出，用它看 Agent 在干嘛、余额还剩多少；代价是它依赖 Python/PySide6，环境不对就装不起来。

适合谁

  • 想在编辑器/浏览器前也能看到 Agent 状态的人（思考、查找、修改、执行、完成）。
  • 喜欢摸头、戳身体、碰尾巴这类互动的人（养鱼党的"陪伴感"）。
  • 用桌面端 + WebUI 双端的人：两个客户端各用各自配置。

解决什么

  • 透明、无边框、始终置顶的原生窗口，由插件启动、随 DSH 退出。
  • 显示真实任务状态与进度（项目/步骤/多任务/待办）。
  • 状态气泡与设置页显示 DeepSeek 余额，区分 API Key 与已登录账户。
  • 支持拖动、跨显示器、透明区域点击穿透、大小/气泡/声音/减少动态。

风险点

  • 原生依赖：Windows/Linux/macOS 共用包，但无随架构 Helper 时会回退 Python，需要 PySide6——少这一步就"装了没窗口"。
  • 离线安装必须下 .tgz 安装包，GitHub 自动生成的 Source code (zip) 不是安装包（README 专门强调，说明踩的人多）。
  • 角色素材来自 PC2005-cloud/dsh-pet，二创/分发注意授权。
  • 常驻置顶窗在低配机器上会持续占用资源。

替代品

  • dsh-pet：同为桌宠，动画更多、支持宠物包。
  • dsh-notify-me：只要"状态提醒"不要桌宠。
  • dsh-folia：壁纸 + 桌宠一体，更重。

事实
