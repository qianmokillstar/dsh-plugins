dsh-folia · 壁纸引擎 + 桌宠 + 开机动画

已核实 人工短评 风险 中 🟢 纯本地
一句话结论：比单纯换肤重得多的"氛围全家桶"——本机 WE 壁纸实时渲染、桌宠皮肤、开机动画、本地语音、在线素材站；功能多到你得先想清楚自己要不要这么多。

适合谁

  • 想要"整个界面像游戏/沉浸式空间"的人：壁纸 + 桌宠 + 开机动画一套齐。
  • 已经在 Wallpaper Engine 上有收藏、想接到 DSH 里的人。
  • 喜欢折腾素材、愿意调性能参数的人。

解决什么

  • 本机 WE 壁纸实时渲染：支持 Scene、Web、Video 三种类型。
  • 桌宠与皮肤：内置 10 只立绘，可与 dsh-pet 联动。
  • 开机动画、本地语音对话、在线素材站。
  • 结构上是 7 个独立子包，能力可分开启用。

风险点

  • 包名有两个：README 徽章指向 dsh-plugin-folia，而实际安装名是 dsh-folia；装错包名会"装了没反应"，这是最容易踩的坑。
  • 性能最重的一类：Scene/Web 壁纸实时渲染 + 桌宠 + 开机动画叠在一起，低配机明显掉帧。
  • Node ≥ 22.12，旧环境装不上。
  • 功能面大（壁纸/桌宠/语音/素材站），出问题排查链长；与 dsh-plugin-wallpaper-engine 同时装容易冲突（同类实现）。
  • 在线素材站涉及第三方内容与版权。

替代品

  • dsh-plugin-wallpaper-engine：只做壁纸，轻一些。
  • dsh-pet：只做桌宠。
  • dsh-dream-skin：纯 token 换肤，最轻。

事实

  • 安装 spec：dsh-folia@4.26.0-pre.64（npm，预发布版本）· 许可证 MIT · 隔离 profile 安装成功（2026-11-18）
  • 来源：npm · 上游仓库
  • 审核日期 2026-11-18 · 依据该版本 README 原文
  • 隐私：🟢 纯本地（壁纸与桌宠在本机渲染；在线素材站联网）
