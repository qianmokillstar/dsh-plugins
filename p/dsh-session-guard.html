dsh-session-guard · 高峰时段自动闸门

已核实 人工短评 风险 中 🟢 纯本地
一句话结论：给请求加一道"看时段"的闸：高峰自动暂停、周末放行、识别官方来源、按会话冻结并可后台自动重试——本质是省钱与限流工具。

适合谁

  • 在意峰谷价格、希望高峰期自动停手的人。
  • 长任务跑着，希望它在闲时自动继续的人。
  • 多会话并行、想按会话单独冻结的人。

解决什么

  • 高峰自动暂停 + 周末模式（按官方峰谷时段判定）。
  • 二维识别"官方来源"，避免把自建通道误当官方。
  • 会话级冻结：只冻结某个会话，不影响其它。
  • 后端自动重试：被闸住的请求在后台排队重试。

风险点

  • README 默认语言是俄语（多语言里有中文，但要手动切）。
  • 闸门会在高峰卡住你的请求——急用时会觉得"AI 卡了"，先看设置再怀疑故障。
  • 时段规则依赖官方政策，规则变动后插件需跟进。
  • 与 dsh-token-diet 的预算硬停、dsh-live-compact 的压缩叠加时，行为组合需要自己理清。

替代品

  • dsh-token-diet：按预算停，不按时段。
  • 手动避开高峰：零安装，最可控。
  • dsh-cost-meter：只看账不拦。

  • 安装 spec：dsh-session-guard@4.2.10（npm）· 许可证 MIT · 隔离 profile 安装成功（2026-11-18，7s）
