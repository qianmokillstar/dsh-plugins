dsh-context · 上下文洞察面板

已核实 人工短评 风险 低 🟢 纯本地
一句话结论：它不改上下文，只让你看清上下文里装了什么、钱花在哪、子 Agent 各自吃了多少；养鱼时排查"为什么越聊越傻"的第一个工具。

适合谁

  • 聊久了发现模型开始忘事、答非所问，想确认是不是上下文爆了的人。
  • 同时跑多个子 Agent，想知道每个子 Agent 各自占了多少上下文的人。
  • 想知道 7 天 Token / 成本走向，而不只是当轮多少钱的人。

解决什么

  • 上下文洞察页面：一级侧边栏面板，含 7 天 Token/成本 KPI、活动热力图、上下文组成环形图，以及可跳到任一会话的卡片。
  • Context 标签页：上下文统计、组成、趋势、事件、消息与命令执行的仪表板。
  • Fleet 标签页：当前 Agent、父级、每个子 Agent 各一张实时卡片。
  • 右侧栏 Context 面板 + /context 命令：随时看当前上下文组成与近期演变。

风险点

  • 只读，不解决爆上下文：它告诉你"装了什么"，不会自动瘦身；要瘦身得配压缩/清理类插件。
  • 会读取会话与 Token 使用数据并在 UI 里展示，属本机行为，但数据敏感性取决于你的会话内容。
  • 面板本身会占侧边栏位置，小屏幕下需要取舍。

替代品

  • /context 之外什么都不装：只想偶尔看，官方已有基础用量显示。
  • dsh-cost-meter：更偏"钱"的统计与套餐额度，不解释上下文组成。
  • browser 侧栏看会话日志：原始但零安装。
