评测免责声明

本站判断为人工主观评价，不构成安装担保或安全审计结论。

结论怎么来的

  • 阅读插件 README 原文、npm registry 元数据、仓库声明
  • 核对版本、许可证、发布时间、维护者、权限描述
  • 目前以文档核验为主；安装实测记录单独标注为「实测」，并在核验记录页注明 DSH 版本与日期

结论的有效边界

  • 只对核验当日、核验时的那一个版本成立，插件升级后可能失效
  • 风险分级是读文档后的判断，不是代码审计，不能替代安全审查
  • 兼容性如果只写了插件声明的 engines.dsh，会标注"声明值、未实测"
  • 任何"已核实"仅指可安装性，不代表运行正确、不代表无后门
