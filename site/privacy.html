隐私与数据说明

本站收集什么

  • 不收集：不设账号、不写 cookie、不埋统计脚本、不引第三方 CDN 或字体
  • 不收集：不记录你在站内的搜索词或点击行为（搜索完全在浏览器本地完成）
  • 站点是纯静态文件，托管在 GitHub Pages；访问日志由 GitHub 平台按其隐私政策处理，本站无法读取

数据从哪来

  • npm registry 与 downloads API：包名、版本、发布时间、许可证、下载量
  • GitHub API：仓库 star、最近推送、仓库描述、License
  • 插件 README 原文：只在本地阅读核对，不转载、不入库

本地另存的东西

维护者的本机保留 README 原文副本用于事实核对，已通过 .gitignore 排除，不会出现在公开仓库里。
