dsh-free-search · 免 Key 多引擎搜索

已核实 人工短评 风险 中
一句话结论：如果你的 web_search 因为没配 DeepSeek 官方 key 而失效，或者你压根不想为搜索扣官方账户的钱，这个插件一次性解决；但它本质是"多家免费渠道 + 抓页面"的组合，稳定性取决于别人的脸色。

适合谁

  • 用第三方模型供应商、没有 DeepSeek 官方 key，导致内置搜索不可用的人。
  • 配了官方 key，但不想让搜索走官方计费渠道的人。
  • 愿意手动挑引擎、调回退顺序，把搜索成本压到接近零的人。

解决什么

  • 注册一个多引擎搜索 provider 进 ctx.web，内置 web_search 自动选用。
  • 40 个引擎可选：DuckDuckGo、Bing、SearXNG、Exa、Tavily、Brave、Perplexity、Kimi、百度千帆、元宝、知乎等；免费引擎带 FREE 徽章，付费带 API KEY 徽章。
  • 统一回退链：任何引擎失败自动换下一个，结果顶部注明实际生效的引擎；失败按额度/鉴权、反爬、超时分类处理。
  • 多 key 轮换、按 key 冷却、磁盘持久化冷却状态，日志里的 key 一律打码。
  • 设置页可勾选引擎、拖拽回退优先级、一键测试全部引擎、/free-search-engine 弹窗切换。
  • 自带"检查更新"和诊断面板：能看到每个引擎为什么不可用、冷却多久、平均耗时。

风险点

  • 抓页面引擎有代价：baidu-html、so360、sogou、wechat、toutiao 这类是把搜索页抓下来解析，验证码/反爬会按 bot-wall 归类并让整个家族冷却 10 分钟，整段出口 IP 都会被打标。它们默认关闭，建议保持关闭。
  • 第三方条款：免 key 使用各家搜索接口，是否符合对方服务条款由使用者承担；商用前请自行确认。
  • 稳定性不由你控制：免费引擎随时可能限流、改版或失效，回退链能兜底，但结果质量会波动。
  • 密钥面变大：一旦配了多个付费 key，凭据就分散在插件配置里；README 说会打码，但仍建议只配必要的。
  • 版本仍是 0.9.x，接口与引擎清单变化较快。

替代品

  • 官方 dsh-web-search-deepseek / dsh-web-deepseek-api：DeepSeek 官方搜索与抓取，稳定、计费清晰，需要官方 key。
  • dsh-mcp-connector：通过 MCP 接外部搜索服务，配置更通用，但要自己找服务。
  • 手动 web_fetch：零安装，适合少量、目标明确的抓取。
