收录规则与标准

本站为第三方非官方站点，与 DeepSeek / DeepSeek Harness 官方无关联、无授权、无背书。

收录门槛（三选一才算"已核实"）

  • npm 包的 package.json 声明了 dsh.bundle.patch
  • 仓库根 package.json 声明了 dsh 字段（bundle / client / profile）
  • 仓库自带 cordis.patch.yml

只有 README 提到安装方式、拿不到包声明的，可以收录，但必须标「未核实」，不得标「已核实可安装」。

判断标准

每条人工判断必须回答四问，缺一不发布：

  • 适合谁：人群与具体场景，不写"所有人"
  • 解决什么：写能力，能量化就量化
  • 风险点：至少一条真会出事的（凭据 / 隐私 / 成本 / 权限 / 外部依赖）
  • 替代品：至少两个，包含"什么都不装"

排序与收费

推荐序由人工判断给出，不接受付费、不接受指定排名。当前站点没有任何赞助、推广位或付费收录。若未来出现商业合作，会在对应位置显著标注「赞助/推广」。

不收录

  • 要求关闭沙箱 / 审批 / 权限模型才能用的
  • 收集用户数据但不说明用途与存储位置的
  • 只有壳、功能与描述不符的
  • 冒用官方名义但无官方关系的（社区项目会单独标注）
