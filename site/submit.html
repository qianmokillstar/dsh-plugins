提交插件

你可以推荐自己的插件，也可以推荐觉得好用的别人的插件。我们只做一件事：核实它能不能装、装过之后有没有坑。

当前版本还没有后端表单服务，提交入口走 GitHub Issue。字段填完整会被优先处理；只给一个名字的会被排到后面。

下面这段可以直接贴到 DSH 社群、GitHub Issue 或发给维护者：

提交之后会发生什么

  • 我们会先核实：包是否存在、是否有 dsh 声明、版本与许可证
  • 然后试装一次，记录测试的 DSH 版本与日期
  • 通过后进入目录；判断信息不足的，会先标"未核实"上线，不阻塞收录
数据：npm registry / downloads API / GitHub API，构建于 2026-11-17（DSH 0.2.2-rc.3）。
判断信息来自人工阅读 README 与实测；未实测的条目标注"未核实"，不代表安全担保。收录与排序不接受付费。
插件名称、描述、许可证等元数据版权归各作者所有；本站判断为独立评论，仅作必要事实引用。
