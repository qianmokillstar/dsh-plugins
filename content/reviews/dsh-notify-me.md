# dsh-notify-me · 离开页面也能收到提醒

> 一句话结论：去倒水时 Agent 在等你批权限、或后台跑完了，它能弹通知、响提示音、改标题；要转发到 Discord/飞书/Bark 就得把消息内容交给第三方。

## 适合谁

- 长任务跑着、人不敢离开页面的人。
- 用手机/平板盯进度、需要外部推送的人（Discord、Bark、Gotify、飞书群机器人、Server酱、WxPusher、自定义 Webhook）。
- 习惯"窗口留在前台但人不在"的人：超过 3 分钟无输入也算离开。

## 解决什么

- **需要你操作时**：审批、方案确认、提问，用通知 + 提示音 + 标题标记提醒。
- **后台回复完成时**：提醒并可直接点击回到对应对话；提醒时机可选「仅后台 / 仅当前对话静默 / 总是提醒」。
- **离开电脑时**：可转发到外部推送渠道。
- **连页面都关掉时**：可选宿主侧兜底，页面不在时宿主继续推"需要你操作/回复完成"；也可只开同源中继。两项默认关。

## 风险点

- **转发 = 内容出本机**：推到 Discord/飞书/Bark 等渠道时，通知里通常带会话摘要或标题，**私密角色扮演内容会顺手泄露**。高隐私场景请只用本地通知。
- 宿主侧兜底要在 profile 的 patch 层写配置，改错会影响会话启动。
- 外部网关需要各自账号与凭据，凭据管理是额外风险面。
- "窗口在前台但人离开 3 分钟也算离开"——有人会因此收到过多打扰，可调。

## 替代品

- **只用浏览器/系统通知**：零配置，但没有外部推送。
- **`dsh-mobile-plugin`**：手机直接连回来看，不经过第三方推送渠道（但走隧道）。
- **不看通知，靠固定检查**：最简单。
