# @michengai/dsh-skills-manager · 技能统一管理

> 一句话结论：把你散落在 DSH、Claude Code、Cursor 等 20+ 工具里的技能集中到一处管理、预览、备份回退；养鱼时用它统一维护"人设/语气/写作"类技能。

## 适合谁

- 同时用多个 Agent 工具，技能文件散在不同目录、自己都记不清装了什么的人。
- 想给角色扮演准备一套固定技能（语气、场景、写作风格）并统一启停的人。
- 在意"技能常驻会不会吃 token"的人：它会估算技能简介的 Token 开销。

## 解决什么

- **四视图集中管理**：全局技能 / 项目技能 / 发现 / 回收站，支持搜索、状态筛选、来源折叠。
- 兼容 DSH、Claude Code、Codex、Copilot、Cursor、Windsurf、Trae 等 20+ 环境，**不侵入第三方文件**。
- 按来源仓库浏览、分类文件夹拖拽归类、分类级一键启停（分类元数据独立保存）。
- 内置「发现」：ClawHub 热门榜、skills.sh 市场、公开 GitHub 仓库订阅、增量更新与版本备份回退。
- 回收站 + 防误删；技能 Token 成本估算与状态栏实时汇总。

## 风险点

- **会写入本机技能目录**（新建/导入/归类），改错会影响 Agent 行为；好在有回收站，但恢复前提是你没清空它。
- 从 GitHub 订阅技能 = 把外部内容装进本机，**来源可信度要自己判断**，别订阅来路不明的仓库。
- 跨工具扫描会读取各环境目录，隐私敏感机器上注意范围。
- 版本 1.4.x，声明支持到 DSH 0.2.2-rc.3；升级后先看兼容徽章。

## 替代品

- **手动维护 `~/.dsh/skills` 目录**：零安装、完全可控，但跨工具就断了。
- **`dsh-mnemon` 的技能管理**：记忆插件自带的技能区，覆盖面窄。
- **不用技能，只写 AGENTS.md**：最稳，但复用性差。
