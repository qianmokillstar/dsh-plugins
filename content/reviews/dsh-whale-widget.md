# dsh-whale-widget · 小鲸鱼记账挂件

> 一句话结论：右下角常驻的小鲸鱼，用**余额下降反推消费**，不需要任何会话令牌；养鱼党想知道"这一晚聊掉多少钱"，它是门槛最低的一个。

## 适合谁

- 只想看余额和"今天花了多少"，不想装一整套计费面板的人。
- 用 DSH 账号登录态、没建 API key 的人（README 说会自动用登录态取数）。
- 喜欢把提示气泡改成自定义内容/图片的人（泡泡内容模块化，可用 `{cost}` 引用金额）。

## 解决什么

- 常驻自启：余额（60 秒自动刷新，点击可手动刷）、今日已用、每轮对话消耗。
- **记账口径诚实**：余额下降按观测累计为消费，余额上升（充值/赠金）单独记录、不冲掉已有消费，并可手动校正。
- 每轮消耗按模型真实 usage（input/cache/output/reasoning tokens）换算，结束弹泡泡。
- 峰谷定价显示（工作日 9–12、14–18 高峰，周末全天谷价，可倒计时）。
- 明细保留 90 天或 2 万条，逐日归档 365 天，超期归档到本地文件。

## 风险点

- **它记的是"DeepSeek 账户口径"**：只看该 key 的余额变化，不含其它厂商；多供应商混用时数字会偏。
- 余额观测依赖网络与账号态，**断网时只能沿用最近余额**，不报错但也不准。
- 两条产品线（Web 版 / Codex 版）互不兼容，装错会"看不到效果"；npm 名与 `github:` 装法混用会并存冲突。
- 自定义泡泡可放随机图片，来源与版权要自己确认。
