# dsh-connect-workbuddy · 把本机 WorkBuddy 账号接进 DSH

> 一句话结论：省掉在 WorkBuddy 客户端和 DSH 之间来回切；但 README 自己写着"上游已开始限制非官方客户端"，**账号风险自己担**。

## 适合谁

- 本机已经登录 WorkBuddy、想直接在 DSH 里用它的模型的人。
- 需要多账号切换、账号池自动换号的人。
- 想按积分倍率算清每次调用花多少的人。

## 解决什么

- 把本机登录的 WorkBuddy（国内版 + 国际版，两个并行供应商）接到 DSH 的模型选择器。
- 每次刷新按上游目录读取**每个模型的积分倍率**（不写死、不猜），逐模型开关图片输入。
- 多账号切换、账号池自动换号、每日签到、卡片与输入框里的只读积分读数。
- 不提供账号、不共享凭据、不绕过计费：每次调用消耗你自己账号的额度。

## 风险点

- **上游已限制非官方客户端**（README 原文）：接口随时可能失效，**账号存在被风控的风险**。
- 它依赖 WorkBuddy 客户端自身的非官方接口，属于"逆向/抓本机登录态"路线，稳定性不由你控制。
- 积分倍率来自上游，账目仍以官方为准；别拿它当账单依据。
- 版本号 5.x 迭代极快，升级频率高。

## 替代品

- **官方 API key**：最稳、最合法，成本按官方计费。
- **`dsh-codex-subscription`**：同类"把订阅接进 DSH"的思路，风险类似。
- **本地模型**：完全离线，隐私最好，能力看硬件。
