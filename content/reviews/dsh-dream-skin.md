# dsh-dream-skin · 换肤与壁纸

> 一句话结论：想把 DSH 界面从"能用"变成"愿意天天看"，这是目前完成度最高的一套换肤方案；纯 token 实现、不注入、不改安装包，代价几乎只有审美分歧。

## 适合谁

- 长时间盯界面、对配色和留白敏感的人。
- 需要一个能代表团队气质的界面、又要能一键还原的人。
- 喜欢折腾壁纸、强调色、主题包，并愿意分享的人。

## 解决什么

- 8 套原创预设皮肤（Mirage 幻梦系列），浅色/深色兼顾，每套自带弥散光背景，戴上即用。
- DIY 层：换壁纸（本地图 / URL / 渐变）、叠加强调色、拖入或分享一个主题包，内部每个 token 都能改。
- 预设与 DIY 分层独立、互不干扰：预设决定材质与底色，DIY 是纯叠加，随开随关、一键还原。
- 全部走原生 `--dsw-*` token，不改安装包、不注入，理论上不会因 DSH 升级而失效。
- 支持 Web 与 Desktop，8 种界面语言。

## 风险点

- **维护坐标变过**：README 自己说明 GitHub 账号被封后迁到 gitcode，并暂停"已验证/收录"徽章声明。这意味着**源码托管与背书状态需要你自己确认**，本市场不以旧徽章为依据。
- 壁纸支持 URL，等于让界面去请求外部图片；用不可信的 URL 有隐私与可用性风险。
- 主题包可导入，导入的是别人做的配置——虽然只是 token，仍建议只装信任来源的包。
- 版本号已到 11.16.0，迭代非常快，升级频繁。
- 审美是主观的，本市场的"推荐"只代表功能完成度，不代表你会喜欢这套配色。

## 替代品

- **`dsh-claude-style`**：Claude Code 风格的视觉与交互重制，风格取向完全不同。
- **`dsh-folia` / `dsh-plugin-wallpaper-engine`**：偏壁纸引擎（视频、网页、实时渲染），换肤是附加能力。
- **不做任何事**：内置主题已经支持深浅色，够用且零风险。
