# dsh-tts-bridge · 朗读桥（用你自己账号的声音）

> 一句话结论：它不自己合成语音，而是把你选中的会话句子送去 DeepSeek 网页端，用**你账号自带的朗读功能**出声；代价是必须开着那个页面、装一个浏览器扩展。

## 适合谁

- 想让角色"出声"、但不想再接第三方 TTS 服务的人。
- 已经常开 DeepSeek 网页端、有账号朗读功能的人。
- 在意"声音从自己电脑出来"而不是云端合成的人（虽然仍要经过 DeepSeek 页面）。

## 解决什么

- **两部分配合**：DSH 插件盯会话、把"说完一整轮"的话排进队列；Chrome/Edge 扩展取队列、发给 DeepSeek 网页、点它的「朗读」按钮。
- 声音从本机浏览器发出，你不用盯着那个页面看。
- 支持选择要朗读的会话。

## 风险点

- **依赖浏览器扩展与常开页面**：缺一个都不出声；页面关掉就没声音了。
- **必须用 Chromium 内核**（Chrome/Edge/Brave），Firefox 不行。
- 对话内容会发给 DeepSeek 网页端（本来就在用它的对话，但**朗读这一步等于再确认一次内容外发**）。
- GitHub 源安装：实测 19 秒成功（小仓库），但依赖克隆，网络差时会失败。
- 声音质量与可用性取决于你账号的朗读功能，不是插件能控制的。

## 替代品

- **`dsh-fish-soul`**：自带 TTS（可接 OpenAI 兼容 / MiniMax / 豆包），不依赖网页端。
- **`dsh-music-panel`**：只要放音乐不需要朗读。
- **不用语音**：纯文字养鱼，成本最低。
