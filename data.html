1. 目录索引（能直接挂进 DSH）

https://qianmokillstar.github.io/dsh-plugins/index.json —— DSH 市场索引 format 1，可以被 DSH 当成一个插件源直接添加。

DSH 的市场索引配置写在 profile 的 cordis.patch.yml 里（没有 dsh plugin market add 这种命令，dsh plugin 只转发给 pnpm）。在文件里加一段：

- id: plugin-market
  name: "@deepseek-ai/dsh-plugin-market"
  config:
    indexes:
      - https://qianmokillstar.github.io/dsh-plugins/index.json

保存后重启 DSH，插件市场面板里就能看到本站的条目（本站只放公开 npm 元数据与自写判断，格式为 format 1）。

2. 核验记录（带信誉字段）

https://qianmokillstar.github.io/dsh-plugins/verifications.json · schema：verifications.schema.json

{
  "schema": "dsh-market-verification/1",
  "count": 55,
  "entries": [{
    "name": "dsh-mnemon",
    "reviewedVersion": "0.5.46",
    "currentVersion": "0.5.48",
    "stale": true,
    "privacy": "local",
    "risk": "medium",
    "verificationDate": "2026-11-18",
    "install": { "result": "installed", "version": "0.5.46" },
    "judgment": { "fit": "...", "solves": "...", "risk": "...", "alternatives": "..." }
  }]
}

关键枚举：install.result = installed / partial（包落地但没进 bundles）/ failed / not-tested；privacy = local / cloud / unknown。

请务必读 stale：为 true 表示作者已发新版本，本条结论可能过时。

3. 核验徽章（SVG，任何人可引用）

https://qianmokillstar.github.io/dsh-plugins/badges/<插件slug>.svg

[![DSH 核验](https://qianmokillstar.github.io/dsh-plugins/badges/dsh-mnemon.svg)](https://qianmokillstar.github.io/dsh-plugins/p/dsh-mnemon.html)

三种状态：绿色=该版本装成功；琥珀=有新版本或半装；红=安装失败。全部徽章与复制按钮

4. 用这些数据做什么

  • 插件作者：把徽章贴进 README，读者一眼看到"装得起来"
  • 目录类项目：直接把 verifications.json 的 risk / privacy / stale 合进你的列表，比 star 更有信息量
  • 工具作者：做一个"装前体检"脚本，读 stale 与 install.result 决定要不要提醒用户
  • 写作者：引用时带上 verificationDate 与 reviewedVersion，这是本站结论唯一有效的边界

5. 本站不提供的

  • 不提供插件代码分发（只指回 npm / 作者仓库）
  • 不提供"安全认证"或"官方背书"——非官方第三方站点，与 DeepSeek / DSH 官方无关联
  • 不提供实时更新承诺：目录每日 08:17 自动采集一次，核验结论则按人工进度
