养鱼选型速查

如果你只想知道"养鱼该装哪几个"，看这一页。每一格都对应站内已经核验过的插件，点进去能看到完整的四问判断与核验日期。

最省事的起步组合：dsh-mnemon（记忆）+ dsh-live-compact（压缩）+ cc-safety-net（拦截）。三个都不改宿主结构，装完重启即可。

30 天试用建议

  1. 第 1 周：只装记忆那一个（mnemon 或 prime-memory），跑满一周，进记忆库抽查写进去得对不对
  2. 第 2 周：加 dsh-live-compact，观察压缩后回忆是否变差；顺手用 dsh-context 看上下文组成
  3. 第 3 周：人设固化——用 dsh-soul-md 写人设卡，或用 liketavern 的专业流程
  4. 第 4 周：才考虑装饰与手机端；此时你已经知道自己真正在意什么

三条纪律

  • 一次只加一个插件，观察两天再加下一个——否则出问题分不清是谁
  • 改动前备份：人设文件、记忆目录、配置都先复制一份
  • 先看隐私灯：🔴 插件会把内容发出去，私密剧情要有心理准备

养鱼相关插件全清单（按六件事分组）

① 长期记忆 · 8 个

  • dsh-mnemon — 给 DSH 的分层、可见记忆：工作记忆、项目档案与长期证据分离，来源与策略可插拔，本地存储或接入 8 种第三方 Provider。 🟢 纯本地
  • dsh-prime-memory — 把对话压成 L0 捕获→L1 原子记忆→L2 场景→L3 画像四层，并在每次模型调用前自动召回注入。 🔴 需云端
  • dsh-fish-memory — 每条记忆带时间、会淡忘，只有当前这句话检索命中才注入上下文。 🔴 需云端
  • meow-memory — soul/user/project/fact/lesson/topic/rules 七层记忆，首轮注入 + 逐条命中 + 闲置整合。 🔴 需云端
  • memory-eternal — 本机 SQLite 记忆 + 可选云同步，支持热切换与断点续传；云同步即内容上云。 🔴 需云端
  • dsh-plugin-memory — 记忆就是 markdown + git，SOUL.md 作人格，启动时硬注入；曾有“装了无法新建会话”的版本事故（0.19.2 已修）。 🟢 纯本地
  • dsh-memory-nebula — 把别的插件的记忆只读聚合成关联星云，9 个工具顺链检索，可导出单文件 HTML。 🟢 纯本地
  • dsh-loci — 提示词里只放索引（约 1.3k token），细节靠检索按需推门；空库注入 0 字节。 🟢 纯本地

② 上下文瘦身与限额 · 4 个

  • dsh-live-compact — 把长工具输出就地压短，本机完成、压缩前先备份；默认上下文到 2 万 token 才动手。 🟢 纯本地
  • dsh-context — 只读的上下文仪表盘：Token/成本趋势、上下文组成、每个子 Agent 一张卡片；它告诉你装了什么，不负责瘦身。 🟢 纯本地
  • dsh-token-diet — 给每个会话设 Token 预算红线，到 100% 在下一步请求前直接停下；同时按供应商/模型/工作区统计用量。 🟢 纯本地
  • dsh-session-guard — 高峰自动暂停、周末放行、按会话冻结并可后台重试；本质是省钱限流，急用时会觉得“AI 卡了”。 🟢 纯本地

③ 人设防崩 · 3 个

  • dsh-soul-md — 会话级/工作区级可切换的人设卡，记忆存成 markdown 文件由模型读写；不保证模型真的去改。 🟢 纯本地
  • dsh-liketavern — 兼容 ST 角色卡/世界书/预设，剧情状态按分支隔离、重试不串味；装法特殊（GitHub 源）且需 Node ≥24。 🟢 纯本地
  • dsh-fish-soul — 同一个“她”跨 QQ/B站/抖音，按人记忆、作息、主动开口；账号风险与隐私面最大。 🔴 需云端

④ 隐私与权限 · 4 个

  • cc-safety-net — 在工具执行前拦住删库、改权限、读 .env/SSH 私钥这类操作；它自己明说不是沙箱，别当安全边界。 🟢 纯本地
  • dsh-perm-gate — 确定性优先、默认拒绝的权限门：凭据/受保护路径/危险 shell 硬拒，P0 不可被任何规则或人工覆盖。 🟢 纯本地
  • dsh-windows-mcp — 通过 DSH 自带 MCP 桥接入 Windows-MCP：截屏、UI 自动化、输入、剪贴板、进程与注册表，默认关闭且按会话授权。 🟢 纯本地
  • dsh-see-now — 只传“画面变了”的帧并拼成一张图，静止屏幕几乎不出图；屏幕内容会进模型。 🔴 需云端

⑤ 离开电脑 · 5 个

  • dsh-mobile-plugin — 手机 App 通过中转隧道或局域网连回你自己电脑上的 DSH；躺床上也能接着聊，但隧道会经过第三方。 🔴 需云端
  • ds-harness-remote — 端到端加密的远程接入，并给 Agent 一组会话/文件操作工具；授权设备等于第二把钥匙。 🔴 需云端
  • dsh-notify-me — 审批/完成时弹通知、响铃、改标题；可选转发到 Discord/飞书/Bark 等，转发即内容出本机。 🔴 需云端
  • dsh-onebot-qq — 零 Python 的 OneBot 11 通道，让 QQ 消息进 Agent；它是通道不是人格，群聊里乱说话要自己配好设定。 🔴 需云端
  • dsh-bili-scroll — 每天搜 B 站、读字幕原文写报告，可选自动评论 @ 你；带本地转写要 1 GB，版本不满足时会被静默跳过。 🔴 需云端

⑥ 氛围与表达 · 10 个

  • dsh-pet — 一百多个透明动画、跟随会话事件变状态，支持宠物包与脱离浏览器的桌面独立窗。 🟢 纯本地
  • dsh-dafeiyu — 原生置顶小窗，随 DSH 启停，显示任务状态与余额；依赖 Python/PySide6，环境不对装不起来。 🟢 纯本地
  • dsh-meme — 输入框一键发图、AI 按气氛接梗；图库可自建或从市场装，但会占用上下文。 🟢 纯本地
  • deep-view — 把图表、表格、滑块、表单画成会话里的可点卡片；纯展示秒回，带输入的要等你回答。 🟢 纯本地
  • dsh-genui — 把回复变成可点的计算器/表单/图表，结果回流到对话；与 deep-view 同赛道。 🟢 纯本地
  • dsh-plugin-wallpaper-engine — 把本机 Wallpaper Engine 的 Scene/Web/视频壁纸做成对话背景，不注册工具、不注入提示词，不花模型 token。 🟢 纯本地
  • dsh-folia — 氛围全家桶：WE 壁纸实时渲染、桌宠皮肤、开机动画、本地语音、在线素材站；注意 npm 包名是 dsh-folia。 🟢 纯本地
  • dsh-dream-skin — 8 套原创皮肤，外加壁纸、强调色与可分享主题包，全部走原生 --dsw-* token，不注入、不改安装包。 🟢 纯本地
  • dsh-music-panel — 本地曲库 + 多在线源 + 自建 Navidrome 的内嵌播放器；许可证是 AGPL-3.0，商用需确认义务。 🔴 需云端
  • dsh-tts-bridge — 把会话句子送去 DeepSeek 网页端用你账号自带朗读出声；要装浏览器扩展且页面必须开着。 🔴 需云端
