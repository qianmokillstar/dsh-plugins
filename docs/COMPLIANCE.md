# 版权与隐私边界

这份文档说明本市场**收什么、不收什么、发布什么、绝不发布什么**。

## 一、我们只处理公开事实

进索引与站点的字段，全部来自 npm 的公开接口：

| 字段 | 来源 | 性质 |
|---|---|---|
| 包名、版本、发布时间 | npm registry 文档 | 公开事实 |
| 许可证、维护者 | npm registry 文档 | 公开事实 |
| 周下载量 | npm downloads API | 公开统计 |
| 首页、仓库地址 | npm registry 文档 | 公开链接 |
| 插件描述 | npm registry 文档（作者填写的介绍） | 作者原创，仅作事实性引用并附 npm 链接 |

**不含**：任何使用者数据、任何本机路径、任何访问者信息。站点是纯静态文件，没有统计脚本、没有 cookie、没有第三方 CDN 请求。

## 二、README 只作本地研究，不对外转载

- `data/readmes/` 里保存的是第三方 README 原文，**只用于本地核对事实**（版本号、能力清单、许可证），不发布、不随站点分发。
- `.gitignore` 已排除该目录；若你要把仓库推到公开托管，这个目录不会被带出去。
- 评测引用遵循"最小必要"：只做短句引用（通常一句、少于 60 字）并标注来自 README，其余全部是独立撰写的改写与判断。

## 三、不复制作者的视觉资产

- 不抓取、不转存、不二次分发任何插件图标、截图、宣传图。
- 站点图标与配色是本项目自绘的通用图形，与任何插件品牌无关。
- 不把插件名做成 logo、不暗示官方关系；社区插件统一标注"社区项目，与官方无关"。

## 四、评测属于评论，不是转载

- 短评的四问（适合谁/解决什么/风险点/替代品）是**独立判断**，不是 README 的翻译或摘抄。
- 事实卡里的版本、许可、下载量、链接属于客观事实，不受版权保护。
- 引用他人 README 的句子仅用于支撑事实陈述，并注明出处。

## 五、隐私：你的信息不出本机

| 风险点 | 现状 |
|---|---|
| 站点对外暴露 | 服务只绑定 `127.0.0.1`，不监听 `0.0.0.0`，局域网也访问不到 |
| 脚本写死本机路径 | 已清理：用 `DSH_NODE_EXECUTABLE` / `DSH_INSTALL_DIR` 环境变量，不再出现用户名与安装路径 |
| 数据外传 | 采集只向 npm 公共接口发 GET；其它外发行为一律没有 |
| 采集内容 | 只有公开的包元数据；没有你的会话、工作区、凭据 |
| git 提交 | `.gitignore` 已排除第三方 README 与研究快照中间件 |

**发布前自查清单**：

1. `grep -r "C:\\Users" .` 应为空
2. `grep -r "E:\\插件市场deepseek" .` 只应出现在 README 的路径说明里（可改成相对路径）
3. `data/readmes/` 未被纳入版本库
4. 站点无外链统计、无 CDN、无字体外链
5. 新增章节若引用了作者原文，逐条确认已标注来源

## 六、如果你要公开发布

1. 先跑上面的自查清单。
2. 站点可直接静态托管（零外部依赖）；但**索引 URL 必须换成公网地址**，因为 DSH 只接受 `http(s)`。
3. 若托管到公网，建议加一行页脚：`本站内容为独立评测，插件版权归各作者所有。`
4. 不要顺带发布 `data/readmes/` 与 `data/catalog.json` 的原始快照——前者含他人原文，后者体积大且会过时。

## 七、边界之外

- 本市场**不做安全审计**：风险等级是读 README 后的判断，不构成安全担保。
- 本市场**不代装、不托管**第三方代码；安装动作由用户在自己的 DSH 里触发。
- 若插件作者要求下架某条评测，我们执行下架并说明原因；但已公开的历史版本不做篡改。
